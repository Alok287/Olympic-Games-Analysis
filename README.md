# Olympic-Games-Analysis
Data analysis and visualization of Olympic Games using Tableau.
Olympic Games Data Analysis | Tableau

Project Overview

This project focuses on analyzing Olympic Games data using Tableau. It aims to explore historical Olympic trends and present meaningful insights through interactive data visualizations and dashboards.

Tools Used

- Tableau
- Data Visualization
- Data Analysis

Project File

"Olympic_Games_Analysis.twbx"

The Tableau packaged workbook contains the project dashboard and its supporting resources.

Key Objectives

- Explore Olympic Games data.
- Analyze participation and historical trends.
- Present data through visual dashboards.
- Identify interesting patterns in Olympic history.

How to View the Project

1. Download the ".twbx" file from this repository.
2. Open Tableau Desktop or Tableau Public.
3. Open the downloaded workbook.
